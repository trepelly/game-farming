# Farm Dashboard

Công cụ tính toán farming NESO — vòng quay tích lũy ACC và mục tiêu ngược.

🔗 **Live:** https://trepelly.github.io/neso-farm

## Tính năng
- Vòng quay tích lũy: farm NESO → mua character → tăng ACC → lặp lại
- Mục tiêu ngược: muốn đạt X ACC thì cần thay đổi biến nào
- Quy đổi: NESO → NXPC → USDT → VND
- Chạy offline hoàn toàn, không cần backend
